# AI Study Memory Assistant 🧠

AI Study Memory Assistant is an intelligent learning companion that remembers weak topics, tracks learning patterns, and gives personalized study support. The system adapts responses based on user interactions, quiz performance, and repeated mistakes to create a smarter and more effective learning experience.

---

# ✨ Features

- 💬 Smart AI Study Chat
- 🧠 Memory-based personalized responses
- 📊 Weak topic detection
- 📝 Adaptive quiz generation
- 📈 Real-time progress tracking
- 🔄 Continuous learning loop
- 🎯 Beginner-friendly explanations
- 🌙 Modern dark UI

---

# 🚀 How It Works

1. User asks study-related questions  
2. System tracks repeated topics and mistakes  
3. Weak areas are identified automatically  
4. Personalized quizzes are generated  
5. Quiz performance updates memory  
6. Future responses become more adaptive and simplified
